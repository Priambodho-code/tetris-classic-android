# Tetris Classic Android (Game Boy Style) 🎮

A classic Tetris game built for Android using modern development tools. This project features a nostalgic retro aesthetic inspired by the original 1989 Game Boy version.

## ✨ Features
- **Classic Gameplay**: Authentic Tetris mechanics including rotation, line clearing, and increasing difficulty.
- **Retro Visuals**: Game Boy green-scale color palette for a nostalgic experience.
- **Modern Tech Stack**: Built entirely with **Jetpack Compose** and **Kotlin**.
- **MVVM Architecture**: Clean and maintainable code structure.
- **Responsive Controls**: On-screen D-pad optimized for mobile play.

## 🛠 Tech Stack
- **Language**: [Kotlin](https://kotlinlang.org/)
- **UI Framework**: [Jetpack Compose](https://developer.android.com/jetpack/compose)
- **Architecture**: MVVM (Model-View-ViewModel)
- **State Management**: Kotlin Coroutines & Flow
